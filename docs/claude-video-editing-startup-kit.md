# Claude 剪片啟動包｜指令填空題清單

> 來源：尼克的 AI 生活實驗室
>
> 用法：把括號裡的內容換成你自己的，整段複製貼給 Claude。

⚠️ **順序不能跳**：① 逐字稿 → ② 確認剪哪裡 → ③ 剪畫面 → ④ 上字幕 → ⑤ 轉檔

（畫面還沒定版就先上字幕，之後改剪點，字幕要整個重做）

---

## ① 出逐字稿

```
幫我把（影片檔名）轉成繁體中文逐字稿，
每句帶時間戳，
並列出所有超過（0.4）秒的停頓位置。
```

---

## ② 決定剪哪裡

```
這支目標長度（40）秒，目前（59）秒。
幫我列出三件事：
1. 哪幾句適合當開場鉤子
2. 哪幾段是滑點，建議剪掉，附理由
3. 光刪停頓能剪到幾秒
先不要動剪，我確認後再說。
```

---

## ③ 剪畫面

```
照剛才確認的清單剪。
開頭空白全砍，
中間停頓壓到（0.2）秒，
只剪畫面，先不要上字幕跟音樂。
```

---

## ④ 上字幕

```
幫我上繁體中文字幕。
字級（48），白字加深色描邊，
距離畫面底部（250）px。
想強調的那句改成（顏色代碼）色，其他維持白色。
```

⚠️ 字幕轉好後先列給我看、改完錯字再燒上去。

---

## ⑤ 轉直式＋修音量

```
轉成（9:16）直式，
音量正規化到 -14 LUFS、峰值 -1.5 dBTP。
```

---

## 進階：丟進剪映加特效

Claude 輸出的是標準 MP4 + SRT 字幕檔。
想加動畫、貼紙、轉場，直接把成品拖進剪映繼續加工，字幕檔也能匯入重新編輯。

## 安裝清單

| 工具 | 做什麼 | 怎麼裝 |
| --- | --- | --- |
| Claude 桌面版 | 指揮中心，用中文交代就好 | claude.com/download 下載，開 Code 分頁（需 Pro 以上付費方案） |
| FFmpeg | 剪輯引擎，不用開軟體就能剪 | Mac: `brew install ffmpeg`<br>Windows: `winget install Gyan.FFmpeg` |
| Whisper | 本機語音辨識，出逐字稿 | `pip install openai-whisper` |
| 中文字型 (Mac) | 沒裝字幕會變方塊 | `brew install --cask font-noto-sans-cjk-tc` |
| 中文字型 (Windows) | 同上 | 指定用「微軟正黑體」 |

裝完確認：終端機輸入 `ffmpeg -version`，跑出版本號就對了。

整條產線 0 元、全開源、不用任何 API key（免付 ElevenLabs 費用）。全程在自己電腦跑，影片不用上傳雲端。

## 卡關自救

| 狀況 | 原因 | 怎麼辦 |
| --- | --- | --- |
| Mac 打 `brew` 找不到指令 | 沒裝 Homebrew | 先到 brew.sh 裝 Homebrew，再回來裝 FFmpeg |
| Windows 打 `winget` 沒反應 | 系統元件太舊 | 到微軟商店更新「應用程式安裝程式」 |
| 打 `pip` 找不到指令 | 沒裝 Python | 到 python.org 下載安裝，記得勾「Add to PATH」 |
| 字幕變 □□□ 方塊 | 中文字型沒裝 | 見上方字型安裝 |
| 安裝到一半 pip 報錯 | Python 版本太新 | 叫 Claude「改用 Python 3.13 建虛擬環境」（3.14 實測有相容性問題） |
